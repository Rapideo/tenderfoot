How to read this. Stories marked V1 are in scope for the first release, which returns everything active sources return without ranking or filtering. Stories marked Later describe the finished product — the prototype draws them, and they are deferred rather than cut.

Granularity, deliberately chosen. One story per thing a person wants that has value on its own. Not tasks, not epics. Where a story would only make sense alongside three others, it was merged; where one hid two distinct wants, it was split. That is the temperature — say if it reads too fine or too coarse and the whole set moves together.

Problem tags map to the four named pains: P1 missing opportunities entirely, P2 finding out too late, P3 noise, P4 no system of record. A story with no problem tag serves the workflow rather than a stated pain — which is worth noticing when prioritising.
